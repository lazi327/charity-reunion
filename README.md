# 公益寻亲平台

> 纯公益性的寻亲服务平台

基于 **Spring Boot 3** + **MySQL** + **MyBatis-Plus** + **Vue 3** 构建的纯公益寻亲服务平台，为失踪者家属与志愿者之间搭建信息桥梁。

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Spring Boot 3.2、MyBatis-Plus 3.5、JWT(jjwt)、Spring Security |
| 数据库 | MySQL 8.0（库名：`cf_dating`） |
| 前端 | Vue 3、Vite 5、Element Plus、Axios、ECharts、wangEditor |
| 匹配算法 | 自研"亲缘雷达"五维引擎（Levenshtein 姓名比对、高斯年龄衰减、31省邻接地理图、Jaccard特征重合、时间分段衰减）+ 本地 NLP-lite 特征抽取器 |

## 项目特性

- **寻亲者端**：注册登录、寻亲信息发布与检索、亲缘雷达智能匹配、寻亲线索管理、问答社区、寻亲指南、站内私信、个人中心
- **管理员后台**：轮播图管理、用户审核与启停、寻亲信息审核/置顶/驳回、线索管理、指南富文本发布、问答屏蔽、消息答疑、登录日志审计、ECharts 统计分析

## 快速启动

### 1. 初始化数据库

```powershell
mysql -uroot -p < sql/init.sql
```

或通过 Navicat/SQLyog 执行 `sql/init.sql`（会自动创建 `cf_dating` 库和演示数据）。

### 2. 启动后端（端口 8081）

支持通过环境变量覆盖数据库账号密码与 JWT 密钥：

| 环境变量 | 默认值 | 说明 |
|---------|--------|------|
| `DB_USERNAME` | `root` | MySQL 用户名 |
| `DB_PASSWORD` | `root` | MySQL 密码 |
| `JWT_SECRET` | 演示密钥 | 生产环境请更换为长度 ≥32 字节的随机串 |

```powershell
cd server
mvn spring-boot:run
```

> 也可使用 IDEA 打开 `server` 目录，运行 `ReunionApplication` 主类。

### 3. 启动前端（端口 5173）

```powershell
cd web
npm install
npm run dev
```

访问 http://localhost:5173

## 核心功能

### 寻亲者端

- **首页**：轮播图、最新寻亲档案、平台数据统计
- **寻亲档案**：按失踪地区/关键字/寻亲类型/性别检索，查看详情与线索列表
- **发布寻亲**：填写失踪人姓名、性别、出生年份、失踪地区/日期、体貌特征、照片上传（需管理员审核）
- **亲缘雷达**：粘贴大白话描述自动抽取特征（性别/年龄/省份/体貌关键词），五维加权引擎全库打分，返回 Top10 候选与逐维得分分解
- **提供线索**：在档案详情页向发布者提交线索，管理收到/提供的线索
- **寻亲问答**：提问、回答、点赞、最新/最热排序，支持私信邀请他人作答
- **寻亲指南**：知识书架，详情页支持自动目录、阅读进度、字号调节
- **站内消息**：与其他用户（含管理员）实时聊天
- **个人中心**：修改资料、上传头像、管理寻亲数据

### 管理端

- **统计分析**：8项指标卡片 + ECharts 图表（失踪人口地区分布、寻亲线索趋势、寻亲类型分布、问答互动）+ 待办提醒
- **轮播图管理**：上传图片、设置跳转地址、排序、上下架
- **用户管理**：注册审核、违规账号停用/启用
- **寻亲信息管理**：审核通过/驳回、置顶/取消置顶、删除
- **线索管理**：核查线索，删除虚假线索
- **指南管理**：wangEditor 富文本发布/编辑/下架
- **问答管理**：屏蔽/删除不合规问题与回复

## 目录结构

```
├── sql/init.sql              # 数据库建表 + 演示数据
├── server/                   # Spring Boot 后端（8081）
│   └── src/main/java/com/charity/reunion/
│       ├── common/           # 统一响应、异常处理
│       ├── config/           # MyBatis-Plus、密码编码器、Web配置
│       ├── controller/       # 寻亲者端 + 管理端 + 亲缘雷达接口
│       ├── dto/              # 登录/注册请求体
│       ├── entity/           # 实体类（8张表）
│       ├── mapper/           # MyBatis-Plus Mapper
│       ├── security/         # JWT、登录拦截器、验证码
│       └── service/          # 特征抽取、匹配引擎
└── web/                      # Vue3 前端（5173）
    └── src/
        ├── layouts/          # 寻亲者端顶栏布局、后台侧栏布局
        ├── views/            # 寻亲者端页面
        ├── views/admin/      # 管理端页面
        ├── router/           # 路由 + 登录/角色守卫
        └── utils/            # axios封装、登录态
```

## MVP 快速运行

1. 执行 `sql/init.sql`
2. `cd server && mvn spring-boot:run`
3. `cd web && npm install && npm run dev`
4. 使用 `s_zhang/123456` 登录体验档案/线索/亲缘雷达/问答
5. 使用 `admin/admin123` 登录后台查看统计图表与审核流程

> 亲缘雷达为纯本地算法，无需任何外部 API Key 即可完整演示。

## 常见问题

- **亲缘雷达命中少**：属正常现象，候选得分阈值 20 分；可放宽省份、减少体貌标签后重试。
- **首页轮播图不显示**：确认已执行 `sql/init.sql` 且后端 8081 已启动。
- **前端提示"网络错误"**：确认后端 8081 已启动。
- **数据库中文乱码**：确认建库字符集为 `utf8mb4`（init.sql 已指定）。
- **演示密码说明**：演示数据使用 `{noop}` 前缀明文存储便于造数；线上注册的新密码自动使用 BCrypt 加密。
- **JWT 密钥**：上线前通过环境变量 `JWT_SECRET` 更换演示密钥。
