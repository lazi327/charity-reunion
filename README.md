# 公益寻亲平台(Spring Boot 3 + MySQL + MyBatis-Plus + Vue 3)

纯公益性的寻亲服务平台,包含 **寻亲者端**(注册登录、寻亲信息发布、寻亲信息检索、亲缘雷达比对、寻亲线索提供、寻亲问答、寻亲指南、站内私信、个人中心)与 **管理员后台**(轮播图管理、用户启停、寻亲信息审核/置顶/驳回、线索管理、指南富文本发布、问答屏蔽、消息答疑、登录日志审计、ECharts 统计分析)。

## 项目简介

**为什么做这个平台**:被拐失散的家庭、寻根的被收养者、走失的阿尔茨海默症老人家属,传统上只能靠贴吧、电视节目和口口相传发布信息,数据分散、格式不一、人工比对成本极高。本平台把这些信息在线化、结构化:统一发布寻亲档案、多维度检索、线索协作与站内沟通,并用算法在全库中自动缩小候选范围,让"大海捞针"变成"按相似度排序的 Top10"。项目为纯公益定位,全流程无任何收费逻辑。

**两端分工**:

- **寻亲者端**:发布失踪/寻根档案(支持照片,需审核)→ 检索他人档案并提供线索 → 用亲缘雷达一键比对全库候选 → 在问答区求助交流、阅读寻亲指南 → 站内私信与管理员和其他寻亲者沟通。
- **管理员后台**:档案审核/置顶/驳回、用户启停、线索核查、指南富文本发布、问答合规管理、在线答疑、登录日志审计,以及 8 项指标卡片 + ECharts 图表的数据统计分析和待办提醒。

**核心特色——亲缘雷达**:不依赖任何第三方大模型或外部 API,纯本地五维加权匹配引擎——姓名用 Levenshtein 编辑距离比对(兼容改名/错字)、年龄差按高斯函数衰减、失踪地按 31 省邻接地理图计算省份相似度、体貌特征用 Jaccard 重合度、失散时长按分段衰减;配合本地 NLP-lite 特征抽取器,粘贴一段大白话描述即可自动抽取性别/年龄/省份/体貌关键词,返回 Top10 候选与逐维得分分解。所有计算在自有服务器内完成,**数据全程不出服务器**,契合寻亲场景对隐私的极高要求。

完整的功能与页面对照表见「五、功能与页面地图」。

## 一、技术栈

| 层 | 技术 |
|---|---|
| 后端 | Spring Boot 3.2 + MyBatis-Plus 3.5 + JWT(jjwt) + spring-security-crypto |
| 数据库 | MySQL 8.0(库名 `cf_reunion`) |
| 前端 | Vue 3 + Vite 5 + Element Plus + Axios + ECharts(统计图表)+ wangEditor(富文本) |
| 匹配算法 | 自研"亲缘雷达"五维引擎(Levenshtein 姓名比对 · 高斯年龄衰减 · 31 省邻接地理图 · Jaccard 特征重合 · 时间分段衰减)+ 本地 NLP-lite 特征抽取器,不依赖任何第三方大模型 |

## 三、快速启动

### 1. 初始化数据库

```powershell
mysql -uroot -p < sql\init.sql
```

或通过 Navicat/SQLyog 打开 `sql/init.sql` 全量执行(会创建 `cf_reunion` 库和演示数据)。

### 2. 启动后端(端口 8081)

- 数据库账号密码与 JWT 密钥支持环境变量覆盖,不设变量时使用演示默认值(开箱即用,无需改 `application.yml`):

| 环境变量 | 演示默认值 | 说明 |
|---|---|---|
| `DB_USERNAME` | `root` | MySQL 用户名 |
| `DB_PASSWORD` | `root` | MySQL 密码,本机 root 密码不同时设置即可 |
| `JWT_SECRET` | 演示密钥 | 生产环境务必换成长度 >= 32 字节的随机串 |

PowerShell 示例:

```powershell
$env:DB_PASSWORD = "你的root密码"
mvn spring-boot:run
```

- 启动:

```powershell
cd server
mvn spring-boot:run
```

(也可用 IDEA 打开 `server` 目录,运行 `DatingApplication` 主类)

### 3. 启动前端(端口 5173)

```powershell
cd web
npm install
npm run dev
```

浏览器访问 <http://localhost:5173>

## 五、功能与页面地图

**寻亲者端**(`/`)
- 首页:轮播图(管理端可配)、快捷入口、最新寻亲档案、平台数据
- 寻亲档案:按失踪地区/关键字/寻亲类型/性别检索,查看详情与线索列表
- 发布寻亲信息:失踪人姓名、性别、出生年份、失踪地区/日期、体貌特征、照片上传(需管理员审核)
- 亲缘雷达:粘贴大白话描述可一键抽取特征(性别/年龄/省份/体貌关键词),五维加权引擎全库打分,返回 Top10 候选与逐维得分分解;纯本地算法,数据不出服务器
- 提供线索:在档案详情页向发布者提交线索(可留联系方式);在"我的寻亲"中管理收到/提供的线索并标记有效/虚假
- 寻亲问答:提问(自动分类)、回答、点赞、最新/最热排序,可私信邀请他人作答
- 寻亲指南:知识书架 + 详情页自动目录(TOC)/阅读进度/字号调节/阅读时长估算
- 我的消息:与其他用户(含管理员)站内聊天,30 秒轮询未读
- 个人中心:修改资料、上传头像、管理我的寻亲数据

**管理端**(`/admin/login`)
- 统计分析:8 项指标卡片 + ECharts 图表(失踪人口地区分布、寻亲线索提供趋势、寻亲信息类型分布、问答互动)+ 待办提醒
- 轮播图管理:上传图片、设置跳转地址、排序、上下架
- 用户管理:注册审核、违规账号停用/启用
- 寻亲信息管理:审核通过/驳回、置顶/取消置顶、删除
- 寻亲线索管理:核查线索,删除虚假线索
- 寻亲指南管理:wangEditor 富文本发布/编辑/下架
- 寻亲问答管理:屏蔽/删除不合规问题与回复(展开行管理回复)
- 我的消息:与寻亲者在线答疑(复用聊天页)

## 九、常见问题

- **亲缘雷达命中少**:属正常现象,候选得分阈值 20 分;可放宽省份、减少体貌标签后重试,特征向量完整度越高结果越准。
- **首页轮播图不显示**:确认已执行 `sql/init.sql` 且后端 8081 已启动(图片来自 `server/upload/` 目录)。
- **前端提示"网络错误"**:确认后端 8081 已启动。
- **数据库中文乱码**:确认建库字符集为 `utf8mb4`(init.sql 已指定)。
- **演示密码说明**:演示数据使用 `{noop}` 前缀明文存储便于造数;线上注册的新密码自动使用 BCrypt 加密。生产部署前请把演示账号密码更新一遍。
- **JWT 密钥**:上线前通过环境变量 `JWT_SECRET` 更换演示密钥。
